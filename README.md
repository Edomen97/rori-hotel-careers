A complete, production-ready **HR Recruitment Portal** for **Rori Hotel Hawassa** – a luxury hotel in Ethiopia. This system combines a premium job board with a powerful HR dashboard to manage candidates, jobs, interviews, and recruitment analytics.

## ✨ Features

### 🎯 For Job Seekers (Public)

| Feature | Description |
|---------|-------------|
| 📋 **Browse Jobs** | Filter by department, location, employment type, and experience level |
| 🔍 **Smart Search** | Search by job title or keywords |
| 📝 **5‑Step Application Wizard** | Clean, user‑friendly form with progress tracking |
| 📎 **CV Upload** | Supports PDF, DOC, DOCX (max 10MB) |
| 📊 **Application Status Tracker** | Visual workflow: `NEW → UNDER REVIEW → SHORTLISTED → INTERVIEW → SELECTED → HIRED` |
| 🧑‍💼 **Talent Pool** | Submit your profile even if no position is open |
| 📱 **Mobile‑Friendly & PWA** | Works as a native app on smartphones |
| ✉️ **Email Notifications** | Automatic status‑update emails |

### 🔐 For HR / Admin

| Feature | Description |
|---------|-------------|
| 📈 **Dashboard** | At‑a‑glance metrics, recent applications, and notification feed |
| 👥 **Candidate Management** | View, search, filter, and sort all applicants |
| 🏷️ **Candidate Tags** | Add custom labels: `Experienced`, `Priority`, `Internal`, etc. |
| 📝 **HR Notes** | Keep internal notes on each candidate |
| ⭐ **Workflow Actions** | Shortlist, reject, schedule interview, select, or hire directly |
| 📅 **Interview Scheduling** | Assign interviews with date, time, type, and location |
| 🗂️ **Talent Pool** | View and manage pre‑registered candidates |
| 📄 **CV Preview & Download** | View or download uploaded resumes |
| 📊 **Recruitment Reports** | Visual analytics with Chart.js (bar, doughnut, line charts) |
| 🔒 **Audit Log** | Complete trail of all admin actions with filters and pagination |
| 🔔 **Notifications** | Real‑time system notifications |

## 🛠️ Technology Stack

| Layer | Technology |
|-------|------------|
| **Backend** | Python 3.10+, Flask 2.3.3 |
| **Database** | SQLAlchemy + SQLite (development) / PostgreSQL (production) |
| **Forms** | Flask‑WTF & WTForms |
| **Frontend** | Bootstrap 5, Bootstrap Icons, Custom CSS |
| **Charts** | Chart.js |
| **PWA** | Service Worker + Manifest.json |
| **Email** | Flask‑Mail (SMTP) |
| **Deployment** | Render.com (via `render.yaml`) |
